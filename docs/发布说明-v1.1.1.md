## 图匠 ChartSmith v1.1.1：把上下文补全的毛刺磨掉

1.1.0 上线了「标题/标签从最近几条消息自动补全」。这个版本没有新功能，只是把真实对话里抽出来的**难看术语**修干净。

### 修了什么

| 之前 | 现在 |
|---|---|
| `Play` + `Integrity` 两个碎片 | `Play Integrity` 一个整体 |
| `先采集设备环境信号` 整段被丢 | 剥掉动词前缀，得到 `设备环境信号` |
| `判定结果会分成`、`这一串是什么顺序`、`几档` 当标签 | 问句/情态/数量碎片被过滤 |
| 自动标题超长被截断成 `Play · Integrity · Droi…` | 按长度上限取舍术语，标题 `Play Integrity · DroidGuard` |
| 长标题被画布裁掉右边 | 画布按标题实际宽度加宽 |
| 图里出现两个 `DroidGuard`（模型写了、兜底又补一次） | 补标签时跳过模型已写过的词 |

```text
最近几条消息：
  画一下这条链路
  Play Integrity 判定链怎么走的？
  DroidGuard 先采集设备环境信号，再看 SUFS 有没有痕迹
  判定结果会分成 MEETS 和 BASIC 几档

模型给的 spec：title="结构图"，env / res 两个节点 label 留空
结果标题：「Play Integrity · DroidGuard」
节点标签：Play Integrity / DroidGuard 判定 / SUFS / 目标应用
```

### 变更

- `context.py`：新增英文词组抽取、动词前缀循环剥离、问句/情态/数量碎片过滤、术语去重。
- `layout.py`：画布宽度会把标题与副标题的实际宽度算进去，长标题不再被裁。
- 测试 61 → 66 项。

### 配置

无新增配置；沿用 1.1.0 的 `context_fill`（默认开）与 `context_messages`（默认 6）。

### 安装 / 升级

**插件市场**：WebUI → 插件 → 插件市场 → 搜索「图匠」或「ChartSmith」→ 安装/更新。

**手动**：

```bash
cd AstrBot/data/plugins
git clone https://github.com/Bb18273645/ChartSmith.git astrbot_plugin_chartsmith
# 已安装的话：git pull 后在插件页点刷新
```

- AstrBot：`>=4.29,<5`（在 4.29.4 上验证）
- 平台：aiocqhttp、telegram、lark、discord、wecom
- 依赖：无新增；不需要网络，只读本机会话历史
- Python：3.10+
