## 图匠 ChartSmith v1.0.0：首个正式版

让 AI 把流程、架构、调用链画成一张**排版好的图片**，直接发到 QQ / Telegram / 飞书里，而不是甩一堆文字。

**模型只给节点和连线，插件负责排版，用 Pillow 在本地画成 PNG 直接发进聊天。**
不需要浏览器、不调用任何第三方渲染服务、零额外依赖。

```text
你：画一下登录流程
机器人：[一张 5 个节点的流程图 PNG]
      认证通过后签发 JWT，前端存 httpOnly Cookie。
```

> v0.1 / v0.2 是内部迭代，**v1.0.0 是第一个正式发布版本**，接口、配置与 JSON 契约从现在起保持稳定。

### 亮点

**1. 本地渲染，零额外依赖**

布局与绘制全部在插件进程内完成，用 AstrBot 自带的 Pillow 出图。
不需要 node、Playwright、mermaid-cli，Docker 镜像不用加东西；一次渲染几十毫秒，离线可用。

**2. 版式稳定，回边不穿节点**

最长路径分层 + 两轮重心排序 + 正交走线；环、失败重试、回调这类回边走图外侧的独立轨道，
不会从同层其它节点背后穿过，状态机那种带环的图也不会被压平。

**3. QQ / Telegram 专门适配**

- 图片与说明**合成一条消息**：QQ 一个气泡发完；TG 是「图 + 一行说明」；
- 发送失败（NapCat 上传超时、TG 侧拒绝）兜底成文字，不抛异常、不让群里静默；
- 默认 **2 倍像素**输出，手机铺满屏宽后文字不糊；
- `max_width` / `max_height` 上限，避免群图被二次压缩；
- **方向自适应**：同时算 TB / LR，挑更窄的那版（手机按屏宽缩放，越窄字越大）。

**4. 不出现豆腐块**

`✅ ❌ ⚠ 🚀` 在中文字体里没有字形，会映射成 `√ × !` 或直接删掉；`★ → ①` 这类保留。

**5. 聊天场景的基础设施**

按内容哈希缓存（7 天 / 200 张）、每会话每分钟限流、超限节点自动截断并注明、
JSON 非法/无节点/渲染失败全部降级成一句话。

### 安装 / 升级

**手动安装**（当前唯一方式；插件市场上架后会补充）

```bash
cd AstrBot/data/plugins
git clone https://github.com/Bb18273645/ChartSmith.git astrbot_plugin_chartsmith
# 已安装的话：git pull 后在插件页点刷新
```

> 目录名保持 `astrbot_plugin_chartsmith`，和 `metadata.yaml` 里的 `name` 一致。

**配置提示词**：WebUI → 人格 → 你正在用的 persona，把
[`提示词.md`](https://github.com/Bb18273645/ChartSmith/blob/main/提示词.md) 第 ① 节贴到系统提示词末尾。
这决定模型「什么时候画」，不做命中率会明显下降。

### 用法

- 让模型自己画：「画一下登录流程」「画一下我们订单系统的架构」；
- 调试指令：`/diagram {JSON}`，中文别名 `/图匠`，不经过模型直接出图。

### 配置项

| 配置 | 默认 | 说明 |
|---|---|---|
| `max_nodes` | 16 | 单图节点上限，超出截断并注明 |
| `max_edges` | 24 | 单图连线上限 |
| `per_minute` | 6 | 每会话每分钟最多渲染几张，`0` 不限 |
| `max_parallel` | 2 | 同时渲染张数 |
| `scale` | 2 | 输出像素倍率（2 = 两倍像素） |
| `max_width` | 2048 | 输出宽度上限（像素） |
| `max_height` | 3200 | 输出高度上限（像素） |
| `auto_direction` | 开 | 自动在 TB / LR 里挑更窄的排版 |
| `font_path` | 空 | 中文字体路径，空则自动探测 |

### 兼容性

- AstrBot：`>=4.29,<5`（在 4.29.4 上验证）
- 平台：aiocqhttp、telegram、lark、discord、wecom
- 依赖：无新增（使用 AstrBot 自带的 Pillow）
- Python：3.10+

### 验证情况

- 42 项单元测试通过（`python -m unittest discover -s tests -v`）；
- 在真实 AstrBot 4.29.4 下导入插件，确认 `render_diagram` 工具注册成功、参数 schema 为 `spec: string`；
- 用真实 `MessageEventResult` / `Image` / `Plain` 组件验证「图片 + 说明」单条消息链、发送失败降级、命令静默返回；
- 6 张预览图由真实渲染链路生成（`preview/`）；
- `ruff format` / `ruff check` 全绿。

### 已知限制

- 跨层正向连线会从中间层节点背后穿过（提示词已要求「只连相邻层」）；
- 单图建议 ≤ 12 节点；16 节点长链路会被 `max_height` 等比缩小；
- TG 的图不能带 caption，说明文字会单独成一条；
- 字体里没有的 emoji 会被替换或删掉；
- 暂不支持暗色主题。
