## 图匠 ChartSmith v1.1.0：贴着对话画图

图不再是一张“没标题的空框流程图”——**标题和节点标签会从最近几条消息里自动补全**。

```text
你：Play Integrity 到底怎么判定？
机器人：先看 DroidGuard 采集的信号，再看 SUFS 的痕迹。
你：那设备环境到判定结果这一串是什么顺序？
机器人：（调 render_diagram，title 留空）
        [一张标题为「设备环境 · 判定结果 · DroidGuard」的流程图]
```

### 新增：上下文补全

- 工具描述与系统提示词里都写明了「标题/label 优先用最近对话里的专有名词」，模型通常自己就写对了；
- 模型偷懒时插件兜底：读最近 `context_messages`（默认 6）条会话消息，抽专有名词——
  - 反引号/引号里的内容（`` `设备环境` ``）
  - 驼峰标识符与缩写（`DroidGuard`、`SUFS`、`JWT`）
  - 中文术语片段（剥掉「从/到/和」等连接词与虚词）
- `title` 缺失或写成「结构图 / 流程图」这类通名 → 用当前消息的主题，或用抽到的术语拼一个；
- 节点 `label` 留空、或干脆等于 `id` → 按术语依次补齐；
- **只补不改**：模型给了标题/标签就一律不动；`/diagram` 调试指令也保持所见即所得。

实现上是纯文本启发式（`context.py`，零额外依赖）：过滤掉「画一下」请求前缀、
「这条链路」指代短语、「这一串是什么顺序」问句碎片、「采集的信号」动词短语，剩下的才当术语。

### 变更

- 工具返回会告诉模型「其中 N 处标题/标签按最近对话自动补全」，避免它以为标签丢了。
- 提示词更新：标题与 label 优先使用最近对话里的专有名词，不要写通名。
- 测试 42 → 61 项（新增 `tests/test_context.py`）。

### 配置

新增两项，都有默认值，旧配置不用改：

| 配置 | 默认 | 说明 |
|---|---|---|
| `context_fill` | 开 | 用最近对话补全缺失的标题/标签（只补不改） |
| `context_messages` | 6 | 参与补全的最近消息条数（含当前消息），`0` 关闭 |

### 安装 / 升级

**插件市场**：WebUI → 插件 → 插件市场 → 搜索「图匠」或「ChartSmith」→ 安装/更新。

**手动**：

```bash
cd AstrBot/data/plugins
git clone https://github.com/Bb18273645/ChartSmith.git astrbot_plugin_chartsmith
# 已安装的话：git pull 后在插件页点刷新
```

### 兼容性

- AstrBot：`>=4.29,<5`（在 4.29.4 上验证）
- 平台：aiocqhttp、telegram、lark、discord、wecom
- 依赖：无新增（使用 AstrBot 自带的 Pillow）；上下文读取只用会话数据库，不发起网络请求
- Python：3.10+

### 验证情况

- 61 项单元测试通过（GitHub Actions：Python 3.10 / 3.12 双绿）；
- 用真实 AstrBot 4.29.4 的会话管理器跑通「当前消息 + 历史术语 → 补全标题/标签」；
- 复核：`context_fill` 关闭后不补全，`/diagram` 路径不受影响。
