## 图匠 ChartSmith v1.0.1：市场图标 + 安全说明

**代码逻辑零改动**，只补上市场展示与安全透明度。

v1.0.0 已通过 AstrBot 插件市场审核（VirusTotal 扫描 `malicious=0, suspicious=0, undetected=65`，
Agent 安全检查通过）并上架。这个版本把两件收尾的事补上：

### 新增

- **`logo.png`（512×512）**：蓝底圆角 + 白色节点/箭头，和插件输出图的配色（`#2563eb`）一致。
  AstrBot 会自动读取它作为插件市场卡片图标。
- **`SECURITY.md`**：写明安全报告渠道与插件边界——
  不发起网络请求、不执行子进程、运行时不使用 `eval`/`exec`/`pickle`、
  只写插件数据目录下的图片缓存、不需要管理员权限、依赖只有 AstrBot 自带的 Pillow。
- README 增加「安全」小节与市场安装说明。

### 变更

- README 顶部加 Logo 与版本徽章，目录补充「安全」条目。
- `metadata.yaml` 版本号 `1.0.1`。

### 安装 / 升级

**插件市场**：WebUI → 插件 → 插件市场 → 搜索「图匠」或「ChartSmith」→ 安装/更新。

**手动**：

```bash
cd AstrBot/data/plugins
git clone https://github.com/Bb18273645/ChartSmith.git astrbot_plugin_chartsmith
# 已安装的话：git pull 后在插件页点刷新
```

### 兼容性

- AstrBot：`>=4.29,<5`（在 4.29.4 上验证）
- 平台：aiocqhttp、telegram、lark、discord、wecom
- 依赖：无新增（使用 AstrBot 自带的 Pillow）
- Python：3.10+

### 验证情况

- 42 项单元测试通过（GitHub Actions：Python 3.10 / 3.12 双绿）；
- `ruff check` 通过；
