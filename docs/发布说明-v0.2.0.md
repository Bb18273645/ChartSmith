## 图匠 ChartSmith v0.2.0：在 QQ / TG 里好好发一张图

一句话：**模型只给节点和连线，插件负责排版，用 Pillow 在本地画成 PNG 直接发进聊天。**

v0.2.0 把重点放在「聊天里实际会踩的坑」上：图片别再被压糊、别和图分成两条消息、失败别静默。

```text
你：画一下登录流程
机器人：[一张 5 个节点的流程图 PNG]
      认证通过后签发 JWT，前端存 httpOnly Cookie。
```

### 这个版本改了什么

**1. 一个气泡发完**

图片和说明文字合成一条消息链：QQ（aiocqhttp / NapCat）上是一个气泡，TG 上是图 + 一行说明。
NapCat 上传超时、TG 侧拒绝时会兜底成一句文字提示——不抛异常给模型，也不让群里静默。

**2. 手机上看得清**

- 输出默认 **2 倍像素**（原来 1 倍，手机铺满屏宽后会被拉糊）；
- 新增 `max_width` / `max_height` 上限，超出等比缩小，避免群图被 QQ 二次压缩；
- 新增**方向自适应**：同时算上下（TB）和左右（LR），挑更窄的那版——手机按屏宽缩放，越窄字越大。

**3. 不再出现豆腐块**

`✅ ❌ ⚠ 🚀` 在中文字体里没有字形，现在会映射成 `√ × !` 或直接删掉；`★ → ①` 这类有的符号保留。

**4. 回边走图外侧**

环、失败重试、回调这类回边，改为先进入层间通道，再走图外侧的独立轨道折回，
不会从同层其它节点背后穿过；状态机那种带环的图不会把整张图压平。

### 安装 / 升级

**插件市场**：WebUI → 插件 → 插件市场 → 搜索「图匠」→ 安装（已装的点更新）。

**手动**：

```bash
cd AstrBot/data/plugins
git clone https://github.com/Bb18273645/astrbot_plugin_chartsmith.git
# 已安装的话：git pull 后在插件页点刷新
```

> 目录名保持 `astrbot_plugin_chartsmith`，和 `metadata.yaml` 里的 `name` 一致。

**升级后建议**：把 [`提示词.md`](https://github.com/Bb18273645/astrbot_plugin_chartsmith/blob/main/提示词.md)
第 ① 节重新贴到人格系统提示词里——这版加入了「direction 可省略」「label 不要用 emoji」等约定。

### 配置变化

新增三项，都有默认值，旧配置不用改：

| 配置 | 默认 | 说明 |
|---|---|---|
| `max_width` | 2048 | 输出宽度上限（像素） |
| `max_height` | 3200 | 输出高度上限（像素） |
| `auto_direction` | 开 | 自动在 TB / LR 里挑更窄的排版 |

注意 `scale` 语义变了：现在是**输出像素倍率**（默认 2 = 两倍像素），不再是内部超采样倍数。

### 兼容性

- AstrBot：`>=4.29,<5`（在 4.29.4 上验证）
- 平台：aiocqhttp、telegram、lark、discord、wecom
- 依赖：无新增（用 AstrBot 自带的 Pillow）
- Python：3.10+

### 验证情况

- 42 项单元测试通过（`python -m unittest discover -s tests -v`）；
- 在真实 AstrBot 4.29.4 下导入插件，确认 `render_diagram` 工具注册成功、参数 schema 为 `spec: string`；
- 用真实 `MessageEventResult` / `Image` / `Plain` 组件验证「图片 + 说明」单条消息链、发送失败降级、命令静默返回；
- `ruff format` / `ruff check` 全绿。

### 已知限制

- 跨层正向连线仍会从中间层节点背后穿过（提示词要求只连相邻层）。
- 单图建议 ≤ 12 节点；16 节点长链路会被 `max_height` 等比缩小。
- TG 的图不能带 caption，说明文字会单独成一条。
- 暂不支持暗色主题。
